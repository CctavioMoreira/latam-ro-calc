# Project instructions

When the user asks for a pull request for this project:

- Always add or update the Novidades for the PR in PT-BR, using a uniquely named JSON fragment in `release-notes/` as described in `docs/releases.md`.
- Include a **Novidades (PT-BR)** section in the PR description. Copy every relevant fragment `logs` value verbatim, preserving wording, accents and punctuation. Do not summarize or translate those values again.
- Before opening or updating the PR, verify that its Novidades section contains exactly the same text as the fragment entries so the user can review what will be published.
